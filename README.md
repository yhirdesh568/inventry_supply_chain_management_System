# Inventory Supply Chain Management System

## Project Overview

A MySQL-based Inventory Supply Chain Management System designed to manage suppliers, products, warehouses, inventory, purchase orders, and sales data.

## Technologies Used

* MySQL
* SQL

## Database Modules

* Suppliers Management
* Products Management
* Warehouse Management
* Inventory Management
* Purchase Order Management
* Purchase Order Details
* Sales Management

## Key Analysis

The project includes SQL queries for:

* Total inventory stock
* Warehouse-wise inventory
* Category-wise inventory
* Inventory value analysis
* Top products by inventory value
* Low-stock products
* Warehouse capacity utilization
* Purchase order analysis
* Supplier-wise purchase analysis
* Pending purchase order value
* Supplier delivery performance
* Product and category analysis

## Database

Database name:

`Inventory_supply_Chain`

## How to Run

1. Open MySQL Workbench.
2. Open `Inventory_Supply_Chain.sql`.
3. Execute the SQL script.
4. Select the `Inventory_supply_Chain` database.
5. Run the analysis queries.
